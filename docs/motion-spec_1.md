# COREX — моушн-система и дизайн-направление

ТЗ для Claude Code. Живая демонстрация: https://claude.ai/code/artifact/c4e9afd5-d78f-4ffd-949d-1ed5efcecfd3

Решения, принятые 27.08.2026: сайт пишет Claude Code (кастомный код), система движения делается целиком. **Хиро остаётся фото-сценой на скролле** — концепция шести кадров сохраняется, меняется только исполнение (вариант с SVG-картой маршрута отклонён).

---

## Диагноз текущей версии

1. Стоковое фото контейнерного порта — самый узнаваемый снимок в нише. Заменить своими кадрами.
2. Декор вместо смысла: бирюзовая кривая, угловые скобки, пастельные квадраты с иконками в карточках.
3. Синий кружок «COREX» в блоке про исполнителей висит вне сетки, читается как наклейка.
4. Шесть кадров хиро ощущаются как шесть слайдов: ничего не живёт между ними.

Отдельно: заголовок «Что возим» в четыре строки.

## Главная идея

Страница — это маршрут, и он не прерывается. В хиро — тонкая линия по нижнему краю с шестью узлами, живущая поверх фотографий и связывающая кадры в один путь. Дальше та же линия становится вертикальной направляющей у левого края с узлом в каждой секции. Форма повторяет тезис «один подрядчик на весь путь».

## Токены движения

```css
:root{
  --e-out:   cubic-bezier(.16, 1, .3, 1);   /* вход элементов — 90% случаев */
  --e-inout: cubic-bezier(.65, 0, .35, 1);  /* смена состояний, счётчики   */
  --e-soft:  cubic-bezier(.33, 1, .68, 1);  /* мелкие ховеры               */
  --t-1: 180ms; --t-2: 360ms; --t-3: 700ms; --t-4: 1200ms;
  --stagger: 70ms; --rise: 22px; --blur: 10px;
}
.reveal    { opacity:0; transform:translateY(var(--rise)); filter:blur(var(--blur)) }
.reveal.in { opacity:1; transform:none; filter:blur(0);
             transition:opacity var(--t-3) var(--e-out),
                        transform var(--t-3) var(--e-out),
                        filter var(--t-3) var(--e-out);
             transition-delay:var(--d, 0ms) }
```

`--d` = индекс × 70мс. IntersectionObserver threshold 0.18, unobserve после срабатывания.

## Хиро — восемь приёмов

Секция 600vh, sticky-контейнер 100vh. `idx = floor(p × 6)`, `local` — положение внутри отрезка. Всё состояние вычисляется из `p` детерминированно, без событийных переключений, иначе сцена не отматывается назад.

1. **Скролл сглажен:** `p += (target - p) * 0.09` в requestAnimationFrame. Сцена получает массу. Главный признак дорогой скролл-анимации.
2. **Камера не останавливается:** scale 1.07 → 1.00 внутри каждого отрезка.
3. **Переход — шторка:** `clip-path: inset(0 0 0 X%)`, X от 100 к 0 за первые 20% отрезка. Не кросс-фейд.
4. **Единый грейд поверх всех кадров:** затемнение сверху и снизу, радиальная виньетка, холодная тень + тёплый подсвет. Превращает разные снимки в одну съёмку — важнее любой анимации.
5. **Зерно 6%:** feTurbulence data-URI, mix-blend-mode overlay.
6. **Текст уходит раньше, чем приходит новый:** старый гаснет к 86% отрезка, новый входит с 10%.
7. **Линия маршрута по нижнему краю** с шестью узлами, заполняется непрерывно через все кадры.
8. **Предзагрузка всех шести изображений** до старта сцены.

Про съёмку: тесные кадры с человеком и предметом (руки на спецификации, этикетка маркировки, погрузчик, пломба, стопка документов), а не общие планы. Общий план терминала выглядит стоком даже когда он свой.

## По остальным блокам

**Четыре плашки.** Появление с расфокусом, stagger 70мс, числа считаются от нуля за 900мс. Исправить перенос четвёртой плашки на две строки — сократить до «Человек в Китае».

**Заголовки секций.** Построчный выезд из-под обрезки, 1200мс, stagger 70мс. Только заголовки секций. «Что возим» переписать в две строки, оговорку про законодательство перенести в подзаголовок.

**Таблица «Без нас».** Строки сверху вниз, stagger 70мс, линии прочерчиваются scaleX слева направо. Синий кружок убрать, вместо него строка-вывод после всех семи строк.

**Сроки.** Полосы scaleX синхронно со счётчиками, 1200мс. Поправить пропорции полос под реальные дни. Добавить диаграмму параллельности сертификации и производства — сейчас эта экспертная мысль спрятана в тексте.

**Калькулятор.** Результат через 400мс полосы ожидания, затем счётчик 900мс. Пауза работает на доверие. Поля: подчёркивание от центра к краям при фокусе.

**Кейсы.** Ручное переключение, подробности - в разделе «Блок кейсов» ниже.

**Что возим.** Шесть карточек появляются от центра к краям.

**Чем это подтверждается.** Карточку «Свой человек в Китае» сделать вдвое шире и первой. «Работаем с 2025 года» вынести из сетки в подпись под блоком.

**Вопросы.** Аккордеон 360мс, стрелка на 180°, высота через grid-template-rows 0fr→1fr.

**Заявка.** Убрать «впишите реальный» из плейсхолдеров. Кнопка с тремя состояниями, галочка прочерчивается за 700мс.

## Блок кейсов - переключение

Скролл-анимации в блоке нет. Кейсы переключает сам посетитель, при этом он сразу видит, что кейсов три и о чём они.

**Данные.** Все кейсы в одном массиве CASES: tab, tabMetric, title, before, done[3], metrics[3], photos[2]. Новый кейс добавляется одной записью без правки вёрстки.

**Десктоп.**
- Слева список вкладок. Видны все кейсы сразу: номер моноширинным «01», название, цифра. Активная вкладка - коралловая черта слева.
- Справа карточка: «01 / 03», заголовок, «Было», «Что сделали», три цифры в ряд (tabular-nums), два фото.
- Все карточки лежат в одной ячейке grid (grid-area: 1 / 1). Высота блока = самый длинный кейс. Высоту не анимировать, страница не прыгает.

**Мобильный (< 900px).** Вкладок нет. Карточки в горизонтальной ленте со scroll-snap, следующая выглядывает справа на 16%. Под лентой счётчик «1 / 3» и тонкая полоса прогресса.

**Управление.** Клик по вкладке, стрелки ← → на клавиатуре, свайп. Без автопрокрутки.

**Переход - асимметричный.** Старое уходит быстро, новое входит неторопливо.
- Старая карточка уходит за 200ms: opacity 1→0, translateX ∓8px, blur 0→6px.
- Новая входит после ухода старой, элементы по очереди: номер, заголовок, было, что сделали, цифры, фото. 700ms на --e-out, stagger 70ms, из translateX ±24px и blur 10px. Шесть элементов - лимит очереди соблюдён.
- Направление: следующий кейс едет справа, предыдущий - слева.
- Цифра в «01 / 03» прокатывается вверх, как на табло.
- Коралловая черта вкладки переезжает к новой через transform, 360ms --e-inout.
- Линия сверху карточки прочерчивается заново: scaleX 0→1, transform-origin left.
- Числовые цифры результата досчитываются от нуля за 900ms только при первом показе каждого кейса.
- Новый клик прерывает текущий переход, анимации не копятся в очередь.

**Первое появление блока.** Шапка и вкладки - обычный .reveal со stagger. Первый кейс входит тем же переходом, что и при переключении.

**Доступность.** role="tablist" / "tab" / "tabpanel", aria-selected, фокус виден.

**prefers-reduced-motion.** Мгновенная смена кейса без движения, все цифры сразу в конечном значении.

## Восемь запретов

1. Анимировать только opacity, transform, filter.
2. Не больше шести элементов в очереди появления.
3. Появление один раз, потом unobserve.
4. Никакого bounce и elastic.
5. Ховер входит быстрее (180мс), чем выходит (260мс).
6. Параллакс максимум 8% скорости скролла.
7. Первый экран не ждёт скролла.
8. prefers-reduced-motion показывает конечное состояние, а не отключает страницу.

## Что ещё выдаёт дорогую работу

- Шум feTurbulence 5–6% поверх тёмных заливок.
- Волосяные линии: 1px с прозрачностью 8–12%, а не сплошной серый.
- `font-variant-numeric: tabular-nums` везде, где цифры в колонках.
- Моноширинный шрифт для данных: сроки, номера шагов, эйброу.
- Заголовки не длиннее двух строк.
- Один акцент в одном месте: коралловый — действие и маршрут, бирюзовый — только данные.
