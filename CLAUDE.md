# COREX landing

Тексты: docs/texts-v3.md — единственный источник копирайта. Не переписывать
формулировки без явного запроса. Если текста для нового элемента нет в файле —
спросить, а не сочинять.

Движение: docs/motion-spec.md — токены и восемь запретов обязательны для всего сайта.
Референс реализации: docs/motion-reference.html.

Правила движения:
- анимировать только opacity, transform и filter; никогда height, width, top, left
- одна кривая для входа элементов: cubic-bezier(.16, 1, .3, 1)
- никакого bounce, elastic, spring
- появление проигрывается один раз, после срабатывания unobserve
- ховер входит за 180ms, возвращается за 260ms
- prefers-reduced-motion показывает конечное состояние, а не отключает страницу
